# Demo web José Herrera

Sitio estático (HTML + CSS + un poco de JS, sin build). Vercel lo publica desde `main` con Root Directory `demos/jose-herrera`.

Estilo: luxury cálido con la paleta oficial (salvia, terracota para botones, arena, oro viejo) y tipografías Fraunces + Nunito Sans. Animaciones: entrada del titular palabra por palabra, revelado de la foto en arco, revelados al hacer scroll, riel de progreso en el Método 4R, parallax suave en las fotos y cinta de credenciales. Todo se desactiva con `prefers-reduced-motion` y el contenido se ve completo sin JavaScript.

Datos del cuestionario de José: sesión de 1 hora, $100.000 presencial y $80.000 online, procesos de 3 a 5 sesiones, consultorio en Portal Estrella (Cra. 24A # 59-67, consultorio 6, Manizales), Instagram @terapiaholistica_by_jose.

Pendiente: testimonios reales, frase propia de José en "Sobre José" y política de privacidad. Tiene `noindex` mientras sea demo.
